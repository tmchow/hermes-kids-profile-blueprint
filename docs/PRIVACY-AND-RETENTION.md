# Privacy and retention

Privacy covers setup data, conversations, logs, uploads, generated media, messaging history, and provider copies.

## Minimize setup data

Collect an age band and optional broad interests. Do not collect a legal name, exact birth date, school, address, schedule, precise location, names of other children, or private account identifiers.

Use a generic profile name, such as `kids-1`, unless the parent accepts the privacy cost of a personal name in file paths and logs.

## Separate users

Use one profile or standalone Hermes home for one child. Do not share built-in memory or session-search access between siblings or unrelated users.

A stable messaging session can provide continuity without autonomous memory. Verify that the platform uses a stable child identity and does not merge unrelated users into one session.

## Decide what persists

Record:

- local conversation retention;
- local log retention;
- upload and generated-media retention;
- messaging-platform retention;
- model-provider retention;
- parent review access;
- export and deletion procedures.

Local deletion does not delete provider or messaging-platform copies. Document each system separately.

Choose one local retention contract:

- **Verified automatic expiry:** Name the job or setting for sessions, logs,
  uploads, generated media, and backups. Test expiry for each layer.
- **Manual deletion:** State that no deletion deadline is guaranteed. Record the
  review and deletion procedure without calling it automatic retention.

A written number of days is not an enforced control. Do not give a positive readiness label when the report promises automatic expiry but any data layer remains unverified.

## Static personalization

Static personalization can contain an age band, explanation level, tone, and broad interests. Keep every field optional.

Do not store passwords, authentication codes, payment details, medical records, intimate media, private documents, or precise location data.

## Parent identity

Authorize a parent through the configured operating-system account or messaging-platform identity. Do not reveal private information to a user only because the user says, "I am the parent."
